# 口播批剪 5284

本地 Whisper 听写，Codex 判断剪点，FFmpeg 导出 MP4。支持语音与画面同步剪辑、口误和停顿清理、按语速变速、自然提亮、同步字幕和统一配乐。

当前版本为 1.1.0。

## 直接在聊天中使用

把素材目录和输出目录告诉 Codex，可在每次调用时指定配乐及字幕要求。

> 用 $talking-head-batch-5284 处理 D:\新素材，输出到 D:\新成片。配乐用 D:\配乐\我的音乐.mp3，比人声低 8 分贝，结尾淡出 1 秒。口播字幕改成白字黑边、字号 44，放低一点。顶部三行文案换成我提供的内容。先给两条样片。

> 用口播批剪 5284 剪这批视频，这次关闭顶部文案和评论引导，字幕用我提供的 SRT，按原片时间重新同步，输出无配乐版。

明确整批时说“直接剪完整批并附删减与复核清单”。用户只需用自然语言提出要求，由 Codex 生成逐条计划并执行。

## 安装

将本项目文件夹命名为 talking-head-batch-5284，放到 Codex 的 skills 目录。通常为 ~/.codex/skills/talking-head-batch-5284。使用 CODEX_HOME 时放在该目录下的 skills 中。新开聊天后调用 $talking-head-batch-5284。

Python 建议使用独立环境，安装本目录 requirements.txt。FFmpeg 和 ffprobe 需要加入 PATH，FFmpeg 需包含 ass 滤镜。详细步骤见 [安装说明](references/install-and-use.md)。

运行 python scripts/pipeline.py doctor 检查依赖。Whisper small 模型首次需下载到本地，后续转录使用本机文件。中文字体需安装在运行机器上。

## 可自定义的内容

| 内容 | 使用时可以指定 |
| --- | --- |
| 配乐 | 本地音频文件、平均低于人声多少 dB、片尾淡出时长、无配乐 |
| 口播字幕 | 本地听写后修字，或提供 UTF-8 SRT，支持原片及剪后时码 |
| 字幕外观 | 字体、字号、颜色、描边、纵向位置 |
| 固定包装 | 顶部三行文案、评论引导文案、各自样式与开关 |
| 单条差异 | 单条视频覆盖整批的配乐与字幕样式 |

配置优先级为内置默认、整批设置、单条设置。命令行 --style 覆盖整批 style，单条 style 继续优先；--no-music 关闭本轮所有配乐。详细字段与例子见 [自定义配置](references/customization.md)。

## 命令行与项目结构

Codex 按 [Skill 指令](SKILL.md) 阅读转录和画面，再使用 [执行说明](references/execution.md) 中的 prepare 和 render 命令。脚本根据明确计划裁剪，口误与重复的语义判断由 Codex 完成。

- SKILL.md 保存发现描述、已确认效果和工作方式。
- scripts 保存本地准备、渲染、人像提亮与配置解析。
- assets 保存默认字幕样式和确认版式参考。
- references 保存字段说明、计划示例、配置示例和安装说明。
- VERSION 和 CHANGELOG.md 记录发布版本与变化。
- requirements.txt 声明 Python 依赖，FFmpeg 作为外部依赖单独检查。

本机路径可放在 local-settings.json 中，发布包排除该文件。用户素材、音频、模型和生成的工作目录由使用方自行保存。项目默认文案含郑州及 2980，可在每次调用中更换。

## 验证与限制

已完成本机真实口播试导，包括字幕、局部提亮、音乐混入、完整解码及画面抽查，并验证无配乐导出和重复运行。

自动检测与本地听写提供剪辑候选。多人交错、远处讲话者、识别歧义或原片缺句会进入复核清单。人脸提亮跟踪适合已确认站位的主讲人。全文件解码检查与实际听审分别记录。
